# Pressmark Studio — PHP Edition

Standalone PHP 8+ application for **Irfan Livestock Farm** (and any custom business) to customize and export print-ready **Letterheads**, **Visiting Cards (Front & Back)**, **Official Stamps**, and **Logos**.

## Requirements
- PHP 7.4 or PHP 8.0+ (works out of the box with XAMPP, Laragon, WAMP, MAMP, Apache, Nginx, or PHP built-in server).
- No database or Composer dependencies required.

## Quick Start
```bash
cd php-app
php -S localhost:8000
```
Then open `http://localhost:8000` in your browser.
